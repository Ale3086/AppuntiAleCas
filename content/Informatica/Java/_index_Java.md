# 📂 Java
Programmazione orientata agli oggetti in Java: architettura JVM, sintassi, modellazione UML con NClass, costruttori, ereditarietà, classi astratte, interfacce e polimorfismo.

### **[[_index_Pratica|Pratica]]**
Prontuario di laboratorio e ricette di sintassi per esercizi al computer: tipi primitivi, metodi String, I/O con Scanner, cicli, array, matrici e template per menu interattivi.

### **[[_index_Teoria|Teoria]]**
Concetti teorici per interrogazioni ed esami orali: architettura JVM, RAM (Stack, Heap, Metaspace), OOP, membri statici, costruttori, UML NClass, classi astratte e polimorfismo.
