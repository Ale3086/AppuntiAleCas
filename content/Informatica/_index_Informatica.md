# 📂 Informatica
Lo studio del pensiero computazionale e della logica di programmazione: programmazione procedurale in C, programmazione di sistema in C++, OOP in Java, scripting moderno in Python, sviluppo Web (HTML, CSS, JS), algoritmi e strutture dati.

### **[[_index_C|C]]**
Programmazione in linguaggio C: sintassi fondamentale, puntatori, strutture e gestione dei file a basso livello con stream FILE* (fopen, fread, fwrite, fseek).

### **[[_index_Cpp|Cpp]]**
Programmazione in C++: gestione della memoria, puntatori, array, funzioni, struct, classi, librerie e algoritmi di ordinamento.

### **[[_index_HTML|HTML]]**
Sviluppo Web Frontend: struttura semantica delle pagine in HTML5, fogli di stile CSS3 e programmazione interattiva con JavaScript.

### **[[_index_Java|Java]]**
Programmazione orientata agli oggetti in Java: architettura JVM, sintassi, modellazione UML con NClass, costruttori, ereditarietà, classi astratte, interfacce e polimorfismo.

### **[[_index_Python|Python]]**
Programmazione in Python: architettura bytecode PVM, collezioni (liste, tuple, set, dict), funzioni avanzate, memory model, OOP, gestione file e algoritmi.
